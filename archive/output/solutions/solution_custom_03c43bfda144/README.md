# todo.py — Simple CLI Todo List

A minimal, dependency-free todo list manager using only Python standard library.

## Run

## Commands

- `python todo.py add "Buy milk"` — Add a new todo
- `python todo.py list` — List all todos
- `python todo.py done 1` — Mark todo #1 as done
- `python todo.py delete 1` — Delete todo #1

## Persistence

Todos are stored in `~/.todos.json` with atomic writes to prevent corruption.
